# ごめんなさAI (Dogeza as a Service - DaaS)

> *「プライドを捨てずに、土下座をクラウドへ」*

現代社会に蔓延する「謝ったら死ぬ病」を先端AIの無駄遣いで解決する、次世代エクストリーム謝罪プラットフォーム。
些細な過失から取り返しのつかない大失態まで、過剰かつドラマチックな演出で相手を呆れさせ、「もういいよ……（笑）」という失笑による免責（苦笑いディール）を成立させます。

---

## 🌟 主な機能

- **罪状告白フェーズ (Confession Form)**
  - 飲食系（名前入りプリンの無断喫食など）、連絡系（「今起きた」を「今出た」と偽装）、業務系（承知していない「承知いたしました」）など、多種多様な罪状カテゴリーに対応。
  - 配偶者、上司、メルカリの取引相手など、関係性に応じた文体最適化。

- **謝罪強度スライダー (Intensity 1 to 5)**
  - **Level 1（平身低頭）**: 「ごめんて」を極限まで丁寧語化。
  - **Level 3（時代劇モード）**: 「腹を切ってお詫び申し上げたく候」武士道スタイル。
  - **Level 5（記者会見モード）**: 激しいカメラフラッシュと2,000字のプレスリリース生成。

- **3Dスライディング土下座ジェネレーター**
  - 物理演算エンジンによる初速・摩擦係数シミュレーション。
  - オプションで額から火花を散らす「バーニング土下座」演出を完備。

- **手土産（ワイロ）推薦エンジン**
  - 罪の重さに応じて、コンビニコーヒーから老舗の羊羹＋全財産まで的確にレコメンド。

- **ワンタップ「全部嘘でした」緊急脱出ボタン**
  - 正気に戻った瞬間、大爆発アニメーションと共に履歴を完全消滅させます。

## 🚀 性能・セキュリティ

- **超高速レスポンス**: 追いLINEが飛んでくる前（1.8秒以内）に謝罪文を錬成。
- **黒歴史の秘匿**: 生成完了から3分後にデータを不可逆破棄。
- **震える指対応UI**: 動揺して指が震えていても誤タップを防ぐメガサイズボタン設計。
